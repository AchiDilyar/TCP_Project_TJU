# TCP 在应用层的设计与实现
## 项目简介
TCP 是Internet 标准协议的经典，是TCP/IP 协议栈的关键协议。通过阅读TCP的标准，本组成员复现了协议的基本功能，达到了以下实践目的： 
1) 理解传输层协议的基本功能，掌握相应协议设计与实现的方法。 
2) 理解面向连接的基本原理，掌握建立连接和拆除连接的设计与实现方法。 
3) 理解流量控制的基本原理，掌握相应协议设计与实现的方法。 
4) 理解可靠数据传输的基本原理，掌握相应协议设计与实现的方法。 
5) 理解拥塞控制的基本原理，掌握相应协议设计与实现的方法。 
6) 具备阅读Internet协议标准并实现的能力。 
7) 提高网络协议设计与实现的能力。 
8) 提高撰写技术报告的能力。 
我们首先根据RFC793 文档设计了基于应用层的实现逻辑。然后使用C语言，在统一的Ubuntu虚拟环境下进行了协议的代码实现。实现了包括“建立连接”，“ 断开连接”，“可靠数据传输”，“流量控制”和“拥塞控制”等功能。并对吞吐率进行了验证，验证了协议实现的正确性。 
我们在报告中撰写了上述五项功能的设计与实现，并通过了三项功能的测试。
